=head1 NAME

Alien::Xrepo::Runtime - consumer class for xrepo-based Aliens (no generated ConfigData)

=head1 SYNOPSIS

    package Alien::Zstd;
    use v5.40;
    use experimental 'class';
    use Alien::Xrepo::Runtime;

    class Alien::Zstd : isa(Alien::Xrepo::Runtime) {
        method pkg_name {
            return [ { name => 'zstd', kind => 'shared' } ];
        }
    }

    1;

=head1 DESCRIPTION

C<Alien::Xrepo::Runtime> is the post-build accessor layer for an xrepo-based
Alien. It deliberately avoids the L<Alien::Base> model of generating a
per-subclass C<::ConfigData> module at build time: package paths are resolved by
asking xrepo itself -- lazily, once per package, cached for the process -- so a
fresh checkout of an Alien using this class works with no build step at all.

Optionally a C<xrepo.json> recipe instead of an inline C<pkg_name>, and a
snapshot written by L<Alien::Xrepo::Build> (auto-detected from the dist share
dir, see C<autodetect_snapshot>) makes resolution fully hermetic: the accessors
then serve recorded paths and never spawn xrepo.

=head1 METHODS

The accessor surface follows the L<Alien::Base> conventions. Each accessor
takes an optional package name and defaults to the primary (first declared)
package.

=over

=item C<cflags>, C<cflags_static>

Include flags (C<-I...>) for the package.

=item C<libs>, C<libs_static>

Link flags (C<-L... -l...>) for the package.

=item C<libpath>, C<ffi_lib>

Absolute path to the package's runtime library (DLL/SO/dylib).

=item C<dynamic_libs>

Absolute paths to every library file xrepo reported.

=item C<bin_dir>

Executable directories (a tool package's C<bin>).

=item C<version>, C<kind>

Version and kind (C<library> for libraries, C<binary> for tools) as reported by xrepo.

=item C<dist_dir>

The package's install root (where its files live).

=item C<install_type>

C<'share'> once any package has resolved, C<'system'> otherwise.

=item C<alt( $name )>

An accessor bound to a non-primary package; C<alt> of the primary returns C<$self>.
E.g. C<< Alien::SDL3->alt('libsdl3_ttf')->cflags >>.

=item C<find_header( $file )>

Absolute path to a header within the package include directories.

=item C<package_info>

The underlying L<Alien::Xrepo::PackageInfo>, or undef before resolution.

=item C<package_names>, C<package_defs>, C<split_flags>

Package metadata and a whitespace flag-splitter (Windows-safe).

=back

=head1 CONSTRUCTOR

    Alien::Zstd->new(
        pkg_name     => 'zstd',                  # or an arrayref of names / hashref defs
        recipe       => $path_or_recipe,         # alternative to inline pkg_name
        install_opts => { kind => 'shared' },    # ambient flags under every package
        root         => $store_root,
        repo         => $alien_xrepo,            # injectable engine
        snapshot     => $file,                   # hermetic data; wins over dynamic fetch
        autodetect_snapshot => 1,                # look in the installed dist share dir
        verbose      => 1,
    )

Subclasses may also declare C<pkg_name> and C<install_opts> as methods, which
the constructor honors when no constructor argument is supplied.
